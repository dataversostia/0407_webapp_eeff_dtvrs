# Radiografia Financiera - Dataversos

Dashboard interactivo de estados financieros (P&G, Balance General, Flujo de Efectivo) con
comparacion de dos periodos (A/B), KPIs financieros y analisis de composicion de ingresos.

Datos de ejemplo (business case ficticio), uso demostrativo.
